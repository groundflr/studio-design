- 2026-05-19 — Fixed the onboarding → dashboard handoff so the welcome banner reliably renders. The `go-to-workspace` and `ex-go-to-dashboard` actions previously navigated to `../dashboard/?welcome=1&role=…` (directory-only path). That works under a webserver (auto-serves `index.html`), but under `file://` browsers don't auto-resolve directory URLs to `index.html` — so the navigation 404'd or showed a directory listing and the dashboard's URL-param read (`?welcome=1&role=`) never ran. Now uses the explicit `../dashboard/index.html?welcome=1&role=…` URL which works in both `http://` and `file://` contexts. The dashboard's existing `getUrlParams()` + `renderWelcome(role)` init logic is unchanged.
