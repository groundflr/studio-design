Component library

The single source of truth for Traverse Studio prototype components. Every component below is a tv-* custom element defined once — edit its file and every prototype updates. Build features by reusing these, not rebuilding them.

Open this page through a local server to load the registry — run python3 -m http.server 4711 from the repo root and visit http://localhost:4711/component-library/, or view it on Vercel.
